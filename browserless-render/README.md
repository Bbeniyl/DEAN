# DEAN persistent browser

This service self-hosts the open-source Browserless Chromium image for DEAN.

Key settings:
- TIMEOUT=-1: no Browserless session timer
- CONCURRENT=1: one browser for DEAN
- TOKEN: generated by Render; never commit it
- HOST=0.0.0.0: reachable through Render

After Render creates the service:
1. Use the service URL as DEAN BROWSERLESS_BASE_URL.
2. Copy the generated TOKEN into DEAN BROWSERLESS_API_KEY.
3. DEAN's existing Browserless client will use the self-hosted service.
